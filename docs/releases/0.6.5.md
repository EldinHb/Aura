## Fixes

- **The Android app no longer crashes at start.** 0.6.4's release build crashed on
  every launch: the home-screen widget library pulled in an old WorkManager whose
  database class lost its constructor when the release build was shrunk. The app now
  uses WorkManager 2.12.0, and the release build fails if that constructor is ever
  stripped again. CI now builds the shrunk release APK too.
- Against a computer still on Aura 0.6.3, the Android app's Changes and Usage views
  say that Aura on that computer needs updating instead of showing a raw error.
