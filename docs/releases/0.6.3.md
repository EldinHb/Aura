## What's new

### Android app: the desktop's new-session options, markdown and team overview

- **New session like the desktop.** Start an agent session, an orchestrator or a
  feature owner (with its goal and autonomy) from the phone, with the same options as
  the desktop: folder, project, worktree and branch, workspace, agent, model, effort,
  permission and sandbox modes, title, group, first prompt and system prompt.
  Paired devices may now create orchestrators and feature owners; terminal sessions,
  custom commands, resumed sessions, custom worktree paths and folders outside your
  projects stay refused. Update the desktop to 0.6.3 for this.
- **Markdown everywhere.** Messages (yours and the agents'), Aura's messages, decision
  cards and reports render markdown like the desktop: headings, emphasis, inline and
  highlighted code blocks, nested and task lists, quotes, tables and links.
- **Team overview.** Orchestrators and feature owners get a Team tab: every worker
  with its role, agent · model · effort, a status chip (Working, Waiting on you, Idle,
  Done, Failed) and its last reply. Feature owners also show the feature's status,
  goal, open questions, checkpoints, decision log and report. Worker tabs show their
  status as a coloured icon, and leader rows in the session list read like
  "1 working · 1 needs you · 1 idle".
